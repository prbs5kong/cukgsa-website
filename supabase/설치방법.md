# 게시판 켜기 — 처음부터 끝까지

> **먼저 솔직하게 말씀드립니다.**
> 이 작업은 **제가 대신 해드릴 수 없습니다.** 계정을 만들고 비밀번호를 정하고
> 결제 정보를 넣는 일이라, 본인 계정으로 직접 하셔야 합니다.
> 대신 아래에 **클릭할 버튼 이름까지** 전부 적었습니다. 순서대로만 따라오세요.
>
> - 걸리는 시간: **30~40분** (기다리는 시간 포함)
> - 비용: **무료**
> - 필요한 것: 구글 계정, 신용카드 **불필요**
>
> 중간에 막히면 `홈페이지주소/pages/setup-check.html` 을 열어 보세요.
> 어디서 막혔는지 정확히 알려줍니다.

## 전체 그림

```
[1] Supabase 계정 만들기        (5분)   ← 데이터가 저장될 곳
[2] 데이터베이스 만들기          (2분)   ← 복사 · 붙여넣기 한 번
[3] 이메일 로그인 설정           (2분)   ← 체크박스 하나만 끄면 끝
[4] 홈페이지에 주소 붙여넣기      (2분)

```

> 회원은 **이메일 + 비밀번호**로 가입합니다. 구글 로그인은 쓰지 않습니다.
> (가입 신청서에서 학과·신분 같은 정보를 함께 받아야 하기 때문입니다)

# [1] Supabase 계정 만들기

1. https://supabase.com 접속 → 오른쪽 위 **Start your project**
2. **Continue with GitHub** 를 누르면 가장 편합니다.
   (GitHub 계정이 없으면 그 자리에서 만들어집니다)
3. 로그인되면 **New project** 를 누릅니다.
4. 입력할 것:

   | 칸 | 넣을 값 |
   |---|---|
   | Name | `kgsa` |
   | Database Password | **Generate a password** 를 누르고, 나온 값을 어딘가에 저장 |
   | Region | **West US (North California)** |
   | Pricing Plan | **Free** |

   > ⚠️ Database Password 는 **다시 볼 수 없습니다.** 메모장에 붙여넣어 두세요.
   > (게시판 운영에는 안 쓰지만, 나중에 문제가 생기면 필요합니다)

5. **Create new project** → **2~3분 기다립니다.** 커피 한 잔 하고 오세요.

---

# [2] 데이터베이스 만들기

1. 왼쪽 메뉴에서 **SQL Editor** (아이콘이 `</>` 처럼 생겼습니다) 클릭
2. **New query** 클릭
3. 이 프로젝트 폴더의 **`supabase/schema.sql`** 파일을 메모장으로 엽니다.
4. **전체 선택 (Cmd+A / Ctrl+A) → 복사 → SQL Editor 에 붙여넣기**
5. 오른쪽 아래 **RUN** 클릭

**"Success. No rows returned"** 이 나오면 성공입니다.

> 빨간 에러가 나오면 일부만 복사된 것입니다. 파일 전체를 다시 복사해서 붙여넣으세요.
> 여러 번 실행해도 안전합니다.

# [3] 이메일 로그인 설정

기본으로 켜져 있으므로 **체크박스 하나만 끄면 됩니다.**

1. Supabase → 왼쪽 메뉴 **Authentication** → **Sign In / Providers**
2. **Email** 항목을 엽니다. (이미 켜져 있습니다)
3. **Confirm email** 스위치를 **끕니다(OFF)** → **Save**

> **왜 끄나요?**
> 켜 두면 가입할 때마다 확인 메일이 나가는데, Supabase 무료 요금제는
> **시간당 2~3통**밖에 못 보냅니다. 개강 직후 여러 명이 동시에 가입하면
> 대부분 메일을 못 받아 가입이 막힙니다.
>
> 끄면 가입 즉시 로그인됩니다. 가짜 이메일로도 가입할 수 있게 되지만,
> 스팸 계정은 **운영 → 회원·차단**에서 바로 막을 수 있으므로 실무상 문제없습니다.

### 돌아올 주소 등록

Supabase → **Authentication** → **URL Configuration**

- **Site URL**: 홈페이지 주소 (예: `https://kgsacub.org`)
  아직 도메인이 없으면 `http://localhost:8000` 을 넣어 두고 나중에 바꾸세요.
- **Redirect URLs** → **Add URL** 로 아래를 **각각** 추가:
  ```
  https://내도메인.org/**
  http://localhost:8000/**
  ```
  (`/**` 까지 꼭 넣어야 합니다)

> 비밀번호 찾기 메일도 같은 이유로 시간당 몇 통 제한이 있습니다.
> 비밀번호를 잊은 회원이 많아지면 Supabase → **Project Settings → Authentication →
> SMTP Settings** 에서 Gmail 등을 연결하면 제한이 풀립니다. (당장은 필요 없습니다)

# [4] 홈페이지에 주소 붙여넣기

1. 이 폴더의 **`assets/js/supabase-config.js`** 를 메모장으로 엽니다.
2. Supabase → **Project Settings → API** 에서 두 값을 복사해 채웁니다.

```js
window.KGSA_SUPABASE = {
  url:     "https://abcdefghijklmnop.supabase.co",
  anonKey: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9....",
};
```

| 넣을 곳 | Supabase 에서 찾는 이름 |
|---|---|
| `url` | **Project URL** |
| `anonKey` | **anon** / **public** 키 (아주 긴 문자열) |

> ⚠️ **`service_role` 키는 절대 넣지 마세요.** 모든 보안을 무시하는 마스터 키입니다.
> 반드시 **anon (public)** 이라고 적힌 것을 쓰세요.
>
> anon 키가 홈페이지 소스에 그대로 보이는 것은 **정상입니다.** 원래 공개되는 값이고,
> 데이터는 `schema.sql` 의 권한 규칙이 지킵니다.

3. 저장하고, 홈페이지를 GitHub 에 다시 올립니다.

# [5] 나를 관리자로 지정

1. 홈페이지를 열고 오른쪽 위 **로그인** → **회원가입** 으로 본인 계정을 만듭니다
2. Supabase → **SQL Editor** → **New query** → 아래를 붙여넣되
   **이메일을 방금 로그인한 본인 것으로 바꿉니다.**

```sql
update public.profiles set role = 'admin' where email = '본인@gmail.com';
```

3. **RUN**
4. 홈페이지로 돌아가 **새로고침** → 상단에 **운영** 메뉴가 생깁니다.

**끝났습니다.** 이제 운영 메뉴에서 행사·후원업체·임원진을 직접 수정할 수 있습니다.

# 확인 · 문제 해결

무엇이든 이상하면 **`홈페이지주소/pages/setup-check.html`** 을 여세요.
1번부터 9번까지 점검해서 막힌 지점과 해결 방법을 알려줍니다.

| 증상 | 원인 |
|---|---|
| 가입해도 로그인이 안 됨 | [3] Confirm email 을 끄지 않음 |
| 로그인 후 "잘못된 주소" 화면 | [3] Redirect URLs 에 `/**` 누락 |
| "운영" 메뉴가 안 보임 | [5] 관리자 지정을 안 했거나 새로고침 안 함 |
| 게시글이 안 불러와짐 | [2] schema.sql 을 안 돌렸음 |
| 갑자기 전부 멈춤 | 무료 프로젝트 일시정지 (아래 참고) |

> ⚠️ **무료 프로젝트는 7일간 접속이 없으면 자동으로 멈춥니다.**
> Supabase 대시보드에서 **Restore** 를 누르면 살아납니다.
> 방학 중에 멈춰 있을 수 있으니 개강 전에 한 번 확인하세요.

# 웹에서 고칠 수 있는 것 (설정 완료 후)

상단 **운영** 메뉴에서 파일 수정 없이, 저장 즉시 반영됩니다.

- **행사** — 다가오는 행사 추가·수정·삭제
- **후원업체** — 업체 추가·수정·삭제
- **임원진** — 이름·직책·학과 (8/28 총회 후 여기서 갱신)
- **연락처** — 대표 이메일, 인스타·페이스북·카카오 주소
- **신고 처리 / 계정 차단 / 공지 고정**

`schema.sql` 을 실행하면 현재 임원 2명과 8/28 정기 총회가 미리 들어갑니다.
후원업체는 비어 있으니 실제 계약한 곳만 추가하세요.

# 스팸 계정 차단

**웹에서 바로 됩니다. 사이트를 다시 올릴 필요 없습니다.**

운영 → **회원 · 차단** → 검색 → **7일 / 30일 / 영구+글삭제**

- **영구+글삭제** = 차단과 동시에 그 계정의 글·댓글을 전부 숨김
- 차단되면 글쓰기·댓글·사진 업로드가 데이터베이스 단계에서 막힙니다 (우회 불가)
- 운영진이 숨긴 글은 작성자가 되살릴 수 없습니다
- 관리자끼리는 서로 차단 불가, 본인도 차단 불가

# 권한 정리

| | 비회원 | 회원 | 차단된 회원 | 운영진 |
|---|---|---|---|---|
| 글·댓글 읽기 | ⭕ | ⭕ | ⭕ | ⭕ |
| 글쓰기·댓글·사진 | ❌ | ⭕ | ❌ | ⭕ |
| 본인 글 수정·삭제 | ❌ | ⭕ | ❌ | ⭕ |
| 남의 글 삭제 | ❌ | ❌ | ❌ | ⭕ |
| 신고하기 | ❌ | ⭕ | ❌ | ⭕ |
| 신고 내용 열람 | ❌ | ❌ | ❌ | ⭕ |
| 행사·임원·후원 수정 | ❌ | ❌ | ❌ | ⭕ |
| 계정 차단 | ❌ | ❌ | ❌ | ⭕ |

운영진 추가:
```sql
update public.profiles set role = 'officer' where email = '새운영진@gmail.com';
```
`officer` 와 `admin` 은 권한이 같지만, **admin 계정은 차단당하지 않습니다.**
회장만 `admin`, 나머지 임원은 `officer` 를 권합니다.

**졸업하는 임원의 권한은 반드시 회수하세요:**
```sql
update public.profiles set role = 'member' where email = '졸업한임원@gmail.com';
```
